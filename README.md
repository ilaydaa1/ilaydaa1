## Featured Projects

### [AI-Powered PDF Knowledge Retrieval](https://github.com/ilaydaa1/AI-Powered-PDF-Knowledge-Retrieval)

A privacy-first, fully local PDF discovery and grounded question-answering assistant.

* Combines dense semantic retrieval with SQLite FTS5/BM25 full-text search
* Uses retrieval fusion and relevance filtering to improve result quality
* Provides grounded answers and match explanations with page-level references
* Runs local language models through Microsoft Foundry Local
* Includes automated tests for retrieval, application, and UI workflows

**Technologies:** Python, Streamlit, ChromaDB, SQLite FTS5, PyMuPDF, Microsoft Foundry Local, pytest

---

### [CogniTwin – Multi-Agent Personal Expert Platform](https://github.com/ilaydaa1/cognitwin-project)

A Computer Engineering capstone project for building domain-specific expert agents within a shared and governed architecture.

* Supports Student, HR Recruitment, Fashion Buyer, and Agile Team workspaces
* Combines vector memory, ontology grounding, role-aware workflows, and validation gates
* Uses structured validation and bounded revision loops to improve reliability
* Supports local and cloud-based LLM providers through a provider-independent architecture
* Developed collaboratively as a team project

**Technologies:** Python, FastAPI, ChromaDB, RDF/SPARQL, Docker, Ollama, pytest

### [Custom Grafana Panel Plugin](https://github.com/ilaydaa1/ik-panel-plugin)

A configurable Grafana visualization plugin that analyzes query results directly within dashboards.

* Calculates average, current, minimum, and maximum values
* Performs rule-based system-state classification
* Detects anomalies using dynamic thresholds
* Provides customizable display options and responsive panel behavior
* Containerized and tested within a Grafana environment

**Technologies:** TypeScript, Grafana Plugin SDK, Docker, CSS Modules
